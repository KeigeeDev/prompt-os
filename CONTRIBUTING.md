# Contributing to PromptOS

Thank you for contributing.

## Before writing code

1. Read the [PRD](./docs/product/PRD.md) and [System Architecture](./docs/architecture/system-architecture.md)
2. Confirm [Milestone 0](./docs/development/mvp-milestones.md) is approved
3. Follow [Coding Standards](./docs/development/coding-standards.md)

## Workflow

1. Branch from `main` using the [branch strategy](./docs/development/git-branch-strategy.md)
2. Commit with [Conventional Commits](./docs/development/git-commit-convention.md)
3. Open a PR with summary, test plan, and linked milestone
4. Ensure lint, typecheck, and tests pass

## Documentation

Update `/docs` when behavior or architecture changes. Add an ADR under `docs/architecture/adr/` for significant decisions.
